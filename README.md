

<!-- ১) null এবং undefined-এর মধ্যে পার্থক্য কী? -->

সহজ কথায়, undefined মানে হলো কোনো কিছু এখনো ঠিক করা হয়নি, আর null মানে হলো কোনো কিছু ইচ্ছাকৃতভাবে খালি রাখা হয়েছে।

Undefined: যখন আপনি একটি ভেরিয়েবল ডিক্লেয়ার করেন কিন্তু তাতে কোনো ভ্যালু বা মান দেন না, তখন জাভাস্ক্রিপ্ট নিজে থেকেই তাকে undefined হিসেবে সেট করে। এটা অনেকটা "ঠিকানা আছে কিন্তু বাড়ি নেই" এমন অবস্থা।

Null: এটি ডেভেলপাররা নিজে ব্যবহার করেন এটা বোঝাতে যে, ভেরিয়েবলটি বর্তমানে "খালি" বা এর কোনো মান নেই। এটা অনেকটা "ইচ্ছাকৃতভাবে খালি রাখা প্লট" এর মতো।
<!-- 
২) map() ফাংশনের কাজ কী? এটি forEach() থেকে কেন আলাদা? -->

map() এবং forEach() উভয়ই একটি অ্যারের (Array) প্রতিটি উপাদানের ওপর কাজ করে, কিন্তু তাদের উদ্দেশ্য আলাদা।

map(): এটি একটি অ্যারের প্রতিটি উপাদানের ওপর কাজ করে এবং ফলাফল দিয়ে একটি নতুন অ্যারে তৈরি করে। অরিজিনাল অ্যারেটি অপরিবর্তিত থাকে।

ব্যবহার: যখন আপনার একটি লিস্ট থেকে নতুন আরেকটি লিস্ট তৈরি করার দরকার হয় (যেমন: সব পণ্যের দাম ২ গুণ করা)।

forEach(): এটি শুধু লুপ চালিয়ে প্রতিটি উপাদানের ওপর কোনো কাজ করে (যেমন: কনসোলে প্রিন্ট করা)। এটি কোনো নতুন অ্যারে রিটার্ন করে না।

ব্যবহার: যখন আপনি শুধু ডাটাগুলো নিয়ে কিছু একটা করতে চান (যেমন: ডাটাবেসে সেভ করা)।


<!-- ৩) == এবং ===-এর মধ্যে পার্থক্য কী? -->

এটি জাভাস্ক্রিপ্টের সবচেয়ে কমন ইন্টারভিউ প্রশ্ন।

== (Loose Equality): এটি শুধুমাত্র ভ্যালু বা মান তুলনা করে। যদি ডাটা টাইপ আলাদা হয়, তবে জাভাস্ক্রিপ্ট জোর করে টাইপ কনভার্ট করে মেলাবার চেষ্টা করে।

উদাহরণ: 5 == "5" এর ফলাফল আসবে true (কারণ মান সমান)।

=== (Strict Equality): এটি ভ্যালু এবং ডাটা টাইপ—উভয়ই তুলনা করে। কোনো জোরপূর্বক টাইপ পরিবর্তন করে না।

উদাহরণ: 5 === "5" এর ফলাফল আসবে false (কারণ একটি নাম্বার, অন্যটি স্ট্রিং)।

<!-- ৪) API ফেচ করার ক্ষেত্রে async/await-এর গুরুত্ব কী? -->

জাভাস্ক্রিপ্ট সাধারণত "Asynchronous" ভাবে কাজ করে, অর্থাৎ এটি কোনো কাজের জন্য অপেক্ষা না করে পরের লাইনে চলে যায়। API থেকে ডাটা আসতে সময় লাগে।

Significance: async/await ব্যবহার করলে কোডটি দেখতে "Synchronous" বা সাধারণ কোডের মতো মনে হয় (এক লাইনের পর এক লাইন)। এটি কোডকে পরিষ্কার রাখে এবং "Callback Hell" বা জটিল প্রমিজ স্ট্রাকচার থেকে মুক্তি দেয়।

কাজ: await শব্দটি জাভাস্ক্রিপ্টকে বলে, "দাঁড়াও, আগে API থেকে ডাটা আসুক, তারপর পরের লাইনে যেও।" এর ফলে ডাটা আসার আগেই কোড রান হয়ে যাওয়ার ভয় থাকে না।


<!-- ৫) জাভাস্ক্রিপ্টে Scope (গ্লোবাল, ফাংশন, ব্লক) কী? -->

Scope নির্ধারণ করে আপনি কোডের কোথায় একটি ভেরিয়েবল ব্যবহার করতে পারবেন।

Global Scope: যদি কোনো ভেরিয়েবল কোনো ফাংশন বা ব্লকের বাইরে লেখা হয়, তবে সেটি গ্লোবাল স্কোপ। এটি কোডের যেকোনো জায়গা থেকে ব্যবহার করা যায়।

Function Scope: একটি ফাংশনের ভেতরে ডিক্লেয়ার করা ভেরিয়েবল শুধুমাত্র ওই ফাংশনের ভেতরেই কাজ করবে। বাইরে থেকে তাকে চেনা যাবে না। (যেমন: var দিয়ে তৈরি ভেরিয়েবল)।

Block Scope: { } (কার্লি ব্র্যাকেট) এর ভেতরে let বা const দিয়ে ডিক্লেয়ার করা ভেরিয়েবল শুধুমাত্র ওই ব্র্যাকেটের ভেতরেই কাজ করে। যেমন if কন্ডিশন বা for লুপের ভেতরের অংশ।
